AARAMBHATHON 2.0 · Problem Statement

Bedroom producers mix in the dark—and one-click "AI mastering" hides why

Independent musicians struggle to judge true loudness, low-end buildup, and phone/laptop speaker translation without expensive acoustic rooms. Generic AI tools rewrite audio blindly without teaching craft or respecting unreleased IP.

1. Loudness Bias

Comparing tracks without LUFS level-matching fools ears into thinking louder = better.

2. Hidden Inter-Sample Overs

Standard sample-peak meters miss +1 dBTP overs created during AAC/Spotify transcoding.

3. Unconsented Audio Uploads

Uploading unreleased stems to opaque AI clouds risks leaks and unrequested training.

Introduction · MixBench

Learn mixing and mastering by doing mixing and mastering

MixBench is a privacy-first acoustic telemetry and coaching workbench powered by one deterministic Python DSP engine and one canonical schema (AnalysisReport v1.0).

Beginner-friendly top 3 prioritized findings tailored to genre & production stage—following What happened → Why it matters → Listen → What to try → Recheck.

Advanced Mix Check

Project Use Case · Live Revision Workflow

From flawed v1 mixdown to verified v2 improvement

Creator Loop

1. Producer uploads unmastered_mix_v1.wav.
2. MixBench flags +3.4 dB buildup at 60–250 Hz and -0.2 dBTP tight headroom.
3. Producer auditions Laptop preview, trims 125 Hz in DAW, exports v2.
4. MixBench verifies headroom and tonal balance improvement.

Methodology & Hybrid Architecture

Browser Web Audio meets stateless Python DSP & Gemini Mentor

Client Web Audio Engine (Next.js 15)

• Direct browser-to-FastAPI uploads (bypasses proxy payload caps)
• Lightweight 44.1 kHz playback proxies keep browser RAM low
• motion/react springs (stiffness: 380, damping: 30) + daylight squircle UI

Python DSP & Gemini API (FastAPI)

• Native sample rates via soundfile + SciPy (zero librosa bloat)
• Deterministic genre/stage/vision evaluator
• Opt-in google-genai structured output with deterministic offline fallback
